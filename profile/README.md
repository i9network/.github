# i9 Networks

**Neurix** — event-driven network operations platform for ISPs and distributed enterprise networks.

Three-plane architecture: **Observability** (telemetry, NetFlow · IPFIX · SNMP) · **Control** (zero-touch provisioning, incident automation) · **Billing** (multi-tenant BSS, reseller coordination)

---

## Platform modules

| Module | What it does |
|--------|-------------|
| **ACS Core** | Zero-touch device provisioning over TR-069 / TR-369 (CWMP + USP) |
| **Hotspot Engine** | Captive portal, bandwidth control, RADIUS auth, voucher pipelines |
| **Threat Shield** | Adaptive DDoS mitigation and threat-intelligence firewall |
| **Deep Logs** | NetFlow v5/v9 + IPFIX + syslog ingestion with AI-assisted traffic visibility |
| **Incident Ops** | Automated escalation pipelines and SLA tracking |
| **Business Support** | Subscriber lifecycle, inventory, reseller billing |

---
