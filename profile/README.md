# i9Network

Building the infrastructure layer for modern ISPs — broadband provisioning, subscriber management, and cloud services designed for scale.

---

## What we build

| Product | Description |
|---------|-------------|
| **ISP Core** | Event-driven microservice platform for subscriber lifecycle, billing, tenant hierarchy, and field operations |
| **i9Cloud Portal** | OpenStack-based cloud reseller control panel (DigitalOcean / Hetzner style) |
| **Field Central** | Offline-first mobile app for field technician workflows |
| **Admin Dashboard** | Web management console for ISP operations teams |
